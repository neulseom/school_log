# 스쿨로그

학교, 학년 반, 날짜를 고르면 그 반의 시간표와 급식, 학교 지역의 날씨를 보여주는 플루터 앱입니다. 네트워크 API 없이 더미 데이터로 동작합니다.

## 화면

앱은 세 장으로 이루어져 있고, 손가락이나 마우스로 좌우로 넘깁니다. 넓은 화면에서는 가운데 홈이 먼저 보입니다.

- **왼쪽.** 선택한 학교와 반, 날짜의 시간표와 급식
- **가운데.** 학교, 학년 반, 날짜를 고르는 홈
- **오른쪽.** 선택한 학교 지역의 시간대별 날씨. `주간 예보`에서 7일을 볼 수 있습니다

아래 점을 눌러도 같은 속도로 넘어갑니다. 키보드 왼쪽·오른쪽 화살표도 동작합니다.

같은 학교, 반, 날짜는 항상 같은 시간표와 급식, 날씨를 만듭니다. 토·일요일에는 수업과 급식이 없습니다. 지역마다 기온과 강수 경향이 다릅니다.

## 실행

Flutter 3.24 이상이 필요합니다.

```bash
flutter pub get
flutter run
```

웹으로 보려면:

```bash
flutter run -d web-server --web-hostname 0.0.0.0 --web-port 47291
```

브라우저에서 `http://127.0.0.1:47291` 을 엽니다.

## 글꼴

화면 글자는 Noto Sans KR, 로고는 Black Han Sans입니다. 두 글꼴은 SIL Open Font License이며 라이선스 원문은 `assets/fonts/`에 있습니다.
